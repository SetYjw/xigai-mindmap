# 《习近平新时代中国特色社会主义思想概论》备考思维导图与真题测试

基于 2023 年版马克思主义理论研究和建设工程重点教材（高等教育出版社、人民出版社）与全国高等教育自学考试官方大纲整理的纯前端静态备考网站，可直接部署至 **GitHub Pages**。

## 功能亮点
- **交互式思维导图**：支持拖拽平移、滚轮缩放、全书总览与单章精读切换、逐级展开“章—节—本章重点与识记/领会/应用考点”。
- **备考清单与背诵遮罩**：按板块和认知层次（识记Ⅰ / 领会Ⅱ / 应用Ⅲ）筛选，支持背诵遮罩自测与章节掌握进度打卡。
- **历年真题测试**：收录 88 道考研政治与全国统考（15040）真实历年真题，支持按板块/章节/题型筛选、即时判分解析与错题本记录。
- **GitHub Pages 适配**：纯静态单文件 `index.html`（无服务端依赖、无根路径资源引用）、内置 SVG Favicon、支持 URL Hash 状态保存（如 `#quiz/ch6`），学习进度与错题记录保存在浏览器本地 `localStorage`。

## 文件说明
- `index.html`：网站主入口文件
- `.nojekyll`：禁用 GitHub Pages 默认的 Jekyll 构建流程，加快部署速度
- `README.md`：项目说明文档
